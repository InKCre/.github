# Get involved with InKCre

Ask questions about using, deploying, or extending InKCre in [Q&A](https://github.com/orgs/InKCre/discussions/categories/q-a). Discuss ideas and direction in [Ideas](https://github.com/orgs/InKCre/discussions/categories/ideas). If you do not know which repository owns a problem, describe your goal, what you tried, and what blocked you; maintainers can help route it.

Report a concrete bug or propose a defined task in its implementation repository:

| Area                                                            | Repository                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Python peer, database contract, CLI, Python extensions          | [impl-py](https://github.com/InKCre/impl-py/issues/new/choose)           |
| Web app, browser extension, TS SDK, Web extension distributions | [impl-ts](https://github.com/InKCre/impl-ts/issues/new/choose)           |
| macOS / Swift peer                                              | [impl-swift](https://github.com/InKCre/impl-swift/issues/new/choose)     |
| UI components and design system                                 | [ui](https://github.com/InKCre/ui/issues/new/choose)                     |
| User manual and developer guides                                | [docs](https://github.com/InKCre/docs/issues/new/choose)                 |
| Extension Registry and Toolkit                                  | [ext-reg](https://github.com/InKCre/ext-reg/issues/new/choose)           |
| Agent skills                                                    | [agent-skills](https://github.com/InKCre/agent-skills/issues/new/choose) |
| Cross-repository collaboration and contribution workflow        | [.github](https://github.com/InKCre/.github/issues/new/choose)           |

Include expected and actual behavior, versions, and the shortest reproduction you can provide. Remove tokens, JWT secrets, connection files, and personal information from logs and screenshots. Report security vulnerabilities through the affected repository's private channel; if no channel exists or ownership is unclear, use the fallback in the [security policy](https://github.com/InKCre/impl-py/security/policy).

To contribute code or documentation, browse [help wanted](https://github.com/issues?q=org%3AInKCre+is%3Aissue+is%3Aopen+label%3A%22help+wanted%22), [good first issue](https://github.com/issues?q=org%3AInKCre+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), and the [current collaboration board](https://github.com/orgs/InKCre/projects/12). Comment on a task to confirm scope and a contact before starting, then follow [Contributing](CONTRIBUTING.md). You can propose work or ask for guidance without submitting code first.

Share extensions, workflows, and experiences in [Show and tell](https://github.com/orgs/InKCre/discussions/categories/show-and-tell). Release and compatibility announcements belong in [Announcements](https://github.com/orgs/InKCre/discussions/categories/announcements).
